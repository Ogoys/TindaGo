# Multi-Store Shopping Guide - Complete User Flow

## 📱 How to Shop at Store B After Switching Cart

This guide explains **exactly** how users can continue shopping at Store B after they've switched their cart from Store A to Store B.

---

## 🎬 Complete Scenario

### Starting Point:
```
User's Favorite Store: "Sari-Sari ni Rosa" (Store A)
User's Cart: Switched to "Tindahan ni Mang Ben" (Store B)
User's Goal: Buy MORE items from Store B
```

## 🎓 Best Practices for Users

### **Shopping at Multiple Stores:**

1. **Start with favorite store** (Store A)
   - Browse normally
   - Add items to cart

2. **Need item from another store?**
   - Search or browse to find it
   - View product details
   - Store name clearly shown

3. **Decision time:**
   - Keep current cart? → Cancel
   - Want the new item? → Replace cart

4. **Continue at new store:**
   - Click **"Browse Store"** button
   - See full Store B catalog
   - Add more items

5. **Complete order:**
   - Checkout at Store B
   - Pick up from one location

6. **Next time:**
   - Home still shows favorite Store A
   - Start fresh shopping session
