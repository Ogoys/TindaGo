# Documentation Location

All project documentation has been moved outside the codebase to reduce storage usage.

## Location
The documentation is now located at:
```
C:\CapsProj\TindaGo-Documentation
```

## Structure
- **archived/** - Completed implementations, fixes, and phases
- **guides/** - How-to guides, testing guides, and quick starts
- **implementations/** - Implementation reports and summaries
- **modules/** - Module-specific documentation
- **setup/** - Setup and configuration guides
- **testing/** - Testing documentation and checklists

## Why Moved?
The `/docs` folder was consuming approximately **2.5MB** of storage in the codebase. Moving it outside keeps the repository lean while preserving all documentation.

## Access
You can access the documentation by navigating to the parent directory:
```bash
cd ../TindaGo-Documentation
```

Or open it directly in your file explorer:
```
C:\CapsProj\TindaGo-Documentation
```
