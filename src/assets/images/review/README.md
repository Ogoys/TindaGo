## Export from Figma
1. Open Figma: https://www.figma.com/design/8I1Nr3vQZllDDknSevstvH/TindaGo-Share?node-id=1428-1773
2. Select store icon in the design
3. Export as PNG @3x (96x96px) or SVG
4. Place in this folder as `store-icon.png`

## Fallback
If icon is not available, the app will use Ionicons 'storefront' icon as fallback.
